# Conventions

- Flat vault, ≤2 folder levels; `[[Home]]` is the MOC.
- Atomic notes, descriptive titles, link with `[[wikilinks]]`; tags only for status (`#active`, `#archived`).
- Every code change updates [[Changelog]] and [[App Overview]]. Move notes to `Archive/`, don't delete.
- Long-form design lives in `docs/DESIGN.md` and `README.md`; the vault links to it rather than copying it.
